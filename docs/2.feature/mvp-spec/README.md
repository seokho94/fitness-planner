- 상태: 초안

FP-11에서 작성한 MVP 상세 명세 9개(T1~T9)의 목록, 읽는 순서, 기능 ID → 화면 → 명세 → 데이터 엔티티 추적 매트릭스, 우선순위 변경 기록, 확장 후보, 문서 간 불일치 점검 결과를 모았다.
개별 규칙은 각 명세 문서에 있고, 이 문서는 규칙을 새로 정하지 않는다.

### 1.1 문서 간 우선순위

1. **데이터·계산 규칙은 T1**, **공통 UI·경로·표시 형식은 T2(IA)** 를 따른다. 기능 명세(T3, T5~T9)는 T1·IA와 다르면 T1·IA를 먼저 고친 뒤 맞춘다(각 문서 머리말).
2. T1·T2와 기능 정의서·사전조사 요약이 다르면 T1·T2를 따른다. 바뀐 내용은 T1 10장, T3 10장, T5 8장, T7 8장, T8 7장에 있다.
3. 기본 운동의 구체 목록은 T4가, 시드가 지켜야 할 규칙은 T3 3.3절이 정한다.

### 6.1 점검 범위와 처리 방침

- 대상: T1~T9 전체와 기준 문서(기능 정의서, 사전조사 요약). 점검일 2026-10-01.
