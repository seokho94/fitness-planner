## 1. 조사 범위와 관점

- 목적: **개인용 헬스 플래너 MVP**(운동 루틴 · 운동 기록 · 체중/체성분 기록)를 만들기 위해 기존 앱의 기능과 UX를 참고한다.
- 국내 앱을 먼저, 깊게 다룬다. 해외 앱은 비교 기준으로 간단히 다룬다.
- 앱별 정리 항목: 핵심 기능 · UX 특징 · 플랫폼/오프라인 · 가격 모델 · 장단점

  3. 휴식 타이머
  4. 운동 라이브러리
  5. 진척 그래프
  6. 체중·체성분 기록

## 2. 국내 앱

### 2.1 플랜핏 (Planfit)

| 항목 | 내용 |
| --- | --- |
| 한 줄 요약 | AI가 루틴을 만들어 주는 국내 대표 "AI 퍼스널 트레이닝" 앱 |
| 플랫폼 | iOS, Android. Apple Watch 연동 (확인 필요). 웹 버전은 없는 것으로 알고 있음 (확인 필요) |
| 오프라인 | 기록 화면은 오프라인에서도 쓸 수 있는 것으로 보이나, AI 루틴 생성과 영상 재생은 네트워크가 필요함 (확인 필요) |
| 가격 모델 | 부분 유료(프리미엄). 기본 기록은 무료, AI 루틴 무제한 생성과 상세 분석은 월·연 구독 (구독명·금액 확인 필요) |

**핵심 기능**

- 루틴 구성: 목표·경력·장비·주당 운동 횟수를 입력하면 AI가 그날의 루틴을 만들어 준다. 직접 루틴을 만들 수도 있다.
- 세트/중량/횟수 기록: 운동 중 화면에서 세트마다 중량과 횟수를 입력하고 완료를 체크한다. 이전 기록을 기준으로 다음 중량을 제안한다.
- 휴식 타이머: 세트를 완료하면 자동으로 시작된다.
- 운동 라이브러리: 운동마다 시범 영상이 있다. 영상 수는 1,000개 이상으로 알려져 있음 (확인 필요).
- 진척 그래프: 운동별 중량·볼륨 추이, 부위별 회복도(근육 피로도 맵)를 보여 준다.
- 체중·체성분: 체중 기록을 지원한다. 체성분 상세 항목 지원 여부는 확인 필요.

**UX 특징**

- 처음 실행할 때 온보딩 설문을 받고, 바로 "오늘의 운동"을 보여 준다. 초보자도 첫 운동을 바로 시작할 수 있다.
- 근육 부위 그림(바디맵)으로 오늘 쓴 부위와 회복 상태를 보여 준다.
- 한국어 운동 이름과 국내 헬스장 기구 기준의 콘텐츠가 많다.

**장단점**

- 장점: 루틴을 고민할 필요가 없다. 시범 영상이 많아 초보자에게 좋다. 국내 사용자 수가 많다.
- 단점: 내 루틴을 그대로 반복하려는 중급자 이상에게는 AI 제안이 번거로울 수 있다. 핵심 기능이 구독에 묶여 있다. 화면 요소가 많다.

### 2.2 번핏 (Burnfit)

| 항목 | 내용 |
| --- | --- |
| 한 줄 요약 | 빠르게 입력하는 데 초점을 둔 국내 운동 기록 앱 |
| 플랫폼 | iOS, Android. 워치 연동 여부는 확인 필요 |
| 오프라인 | 로컬 우선으로 기록하고 계정 동기화를 함께 쓰는 구조로 알고 있음 (확인 필요) |
| 가격 모델 | 부분 유료. 기본 기록은 무료, 고급 통계·테마·광고 제거 등은 유료 구독 (확인 필요) |

**핵심 기능**

- 루틴 구성: 운동을 골라 루틴으로 저장하고 불러와서 시작한다.
- 세트/중량/횟수 기록: 이전 세트 값이 자동으로 채워진다. 한 손으로 빠르게 입력할 수 있는 숫자 입력 UI가 있다.
- 휴식 타이머: 지원한다.
- 운동 라이브러리: 기본 운동 목록과 사용자 정의 운동을 지원한다. 영상은 적거나 없다 (확인 필요).
- 진척 그래프: 운동별 1RM 추정치·볼륨 추이, 월간 통계, 캘린더(운동한 날 표시)를 제공한다.
- 체중·체성분: 체중과 신체 치수(둘레 등) 기록을 지원한다 (체지방률 등 세부 항목은 확인 필요).

**UX 특징**

- 캘린더 중심 홈 화면에서 날짜를 누르면 그날 기록으로 바로 들어간다.
- 화면이 단순하다. 기록 입력에 걸리는 탭 수를 줄였다.
- 운동 완료 후 요약 카드를 공유할 수 있다 (확인 필요).

**장단점**

- 장점: 가볍고 빠르다. 기록만 하려는 사용자에게 맞다. 무료 범위가 넓은 편이다.
- 단점: 루틴 추천이나 코칭 기능이 약하다. 운동 설명 콘텐츠가 부족하다.

- 장점: 체성분 데이터의 신뢰도와 연동성이 가장 좋다. 국내 헬스장 이용자에게 익숙하다.
- 단점: 운동 기록 앱으로는 부족하다. 기기가 없으면 쓸 이유가 적다.

## 3. 해외 앱 (비교 기준)

### 3.1 Strong

- 핵심 기능: 루틴(템플릿) · 세트/중량/횟수 기록 · 자동 휴식 타이머 · 운동 라이브러리(설명·이미지) · 1RM/볼륨 그래프 · 체중·신체 치수 기록. 원판 계산기, 워밍업 세트 계산기가 있다.
- UX 특징: 세트 표(이전 기록 / 중량 / 횟수 / 체크) 형식이 사실상 업계 표준. 군더더기 없는 화면.
- 플랫폼/오프라인: iOS, Android, Apple Watch. 오프라인 우선, 계정 동기화.
- 가격 모델: 무료는 루틴 수 제한(3개로 알려짐, 확인 필요). Strong PRO 월·연 구독 또는 평생 이용권.
- 장점: 빠르고 안정적인 기록 UX. 단점: 무료 제한이 빡빡하다. 영어 전용(한국어 미지원, 확인 필요).

### 3.2 Hevy

- 핵심 기능: 루틴 · 세트 기록(웜업/드롭/실패 세트 구분) · 휴식 타이머 · 운동 라이브러리(애니메이션) · 그래프 · 체중·신체 치수 기록.
- UX 특징: Strong과 비슷한 세트 표 + 소셜 피드(팔로우, 좋아요, 운동 공유).
- 플랫폼/오프라인: iOS, Android, Apple Watch/Wear OS, 웹(루틴 편집). 오프라인 기록 지원.
- 가격 모델: 무료 범위가 넓음(무료 루틴 수 제한 있음, 확인 필요). Hevy Pro 구독/평생 이용권.
- 장점: 무료 범위가 넓고 UI가 현대적이다. 단점: 소셜 기능이 개인 기록 용도에는 불필요하다.

### 3.3 JEFIT

- 핵심 기능: 대형 운동 DB(1,300개 이상으로 알려짐, 확인 필요) · 루틴 플랜 마켓 · 세트 기록 · 휴식 타이머 · 진척 그래프 · 체중·신체 치수 기록.
- UX 특징: 기능이 많고 화면이 복잡하다. 커뮤니티·플랜 공유 중심.
- 플랫폼/오프라인: iOS, Android, 웹. 오프라인 기록 일부 지원 (확인 필요).
- 가격 모델: 무료(광고 있음) + Elite 구독.
- 장점: 운동 DB와 공개 루틴이 풍부하다. 단점: 광고와 복잡한 UI.

### 3.4 FitNotes (참고)

- 핵심 기능: 운동 기록 · 루틴 · 휴식 타이머 · 그래프 · 체중·신체 치수 기록.
- UX 특징: 매우 단순한 기본 Android UI. 날짜(캘린더) 중심.
- 플랫폼/오프라인: Android 전용. 완전 오프라인(로컬 DB), 계정 없음. 백업 파일·CSV 내보내기.
- 가격 모델: 무료, 광고 없음.
- 장점: 개인용 기록 앱의 최소 형태를 잘 보여 준다. 단점: 디자인이 오래됐고 iOS를 지원하지 않는다.

## 5. 시장 특징 (참고, MVP 범위 밖)

- **AI 루틴 추천** (플랜핏 등): 국내 시장에서 가장 눈에 띄는 차별화 요소다. 개인용 MVP에서는 **범위 밖**으로 둔다.
- **웨어러블 연동** (Apple Watch, 갤럭시 워치, 인바디 기기, Apple 건강/Health Connect): 대부분의 상위 앱이 지원한다. MVP에서는 **범위 밖**으로 둔다.
- 소셜·커뮤니티(Hevy, JEFIT), 루틴 마켓, 코치 연결도 흔하지만 개인용 앱에는 필요 없다.
- 수익 모델은 대부분 "기록은 무료, 고급 기능은 구독" 구조다.

## 6. 개인용 MVP에 차용할 점

> 범위: **운동 루틴 · 운동 기록 · 체중/체성분** 으로 한정한다.

### 6.1 운동 루틴

- 루틴(템플릿) 저장 후 불러와서 바로 시작 (Strong, Hevy, 번핏)
- 국내 사용자에게 익숙한 분할 루틴 단위(가슴/등/하체/어깨/팔 등)로 묶기 (짐워크 방식 추정, 국내 헬스 관행)
- 운동 라이브러리는 기본 운동 목록 + 사용자 정의 운동 추가로 시작. 한국어 운동 이름 사용 (플랜핏, 번핏)

### 6.2 운동 기록

- 세트 표 형식: `이전 기록 | 중량 | 횟수 | 완료 체크` (Strong, Hevy)
- 이전 세트/이전 운동 값을 자동으로 채워 입력 횟수 줄이기 (번핏, Strong)
- 세트 완료 시 휴식 타이머 자동 시작, 운동별 기본 휴식 시간 설정 (Strong, 플랜핏)
- 캘린더 홈에서 날짜별 기록 보기 (번핏, FitNotes)
- 운동별 진척 그래프: 최고 중량, 추정 1RM, 볼륨 추이 (Strong, 번핏)
- 오프라인 우선 로컬 저장, 백업/CSV 내보내기 (FitNotes)

### 6.3 체중/체성분

- 체중 + 체성분(골격근량, 체지방량, 체지방률) 직접 입력 (인바디 결과지 항목 기준)
- 체중·골격근량·체지방량을 한 그래프에서 비교 (인바디 앱)
- 운동 기록과 같은 날짜 축으로 체성분 변화 보기 (운동 기록 앱들의 약점 보완)

## 7. 개인용 MVP에 불필요한 점

- AI 루틴 생성·자동 중량 제안 (플랜핏) — 시장 특징으로만 참고, 범위 밖
- 웨어러블·인바디 기기 자동 연동 (인바디, 삼성 헬스, Strong/Hevy 워치 앱) — 범위 밖
- 소셜 피드, 팔로우, 운동 공유 카드 (Hevy, 번핏)
- 루틴 마켓, 커뮤니티, 코치 연결 (JEFIT)
- 대규모 운동 시범 영상 라이브러리 (플랜핏, JEFIT) — 제작·관리 비용이 크다
- 구독 결제, 광고, 무료 기능 제한
- 걸음 수·수면·심박 등 종합 건강 데이터 (삼성 헬스)
